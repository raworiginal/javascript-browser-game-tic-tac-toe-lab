# Tic-Tac-Toe with Unbeatable AI

This project began as an assignment to build a two-player tic-tac-toe game in the browser. I went beyond the requirements by adding a "vs. computer" mode powered by the minimax recursive algorithm.

## Features

* Two-player mode
* Computer opponent using minimax for decision-making
* Unbeatable AI that always wins or forces a draw
* Browser-based interface built with JavaScript, HTML, and CSS

## Beyond the Assignment

While the assignment stopped at two human players, I implemented an AI opponent using minimax. This added:

* Recursive algorithm design and implementation
* Application of computer science fundamentals (game trees and decision-making)
* A more challenging and polished game experience
